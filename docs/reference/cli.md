```text
Usage: nih [OPTIONS] COMMAND [ARGS]...                                         
                                                                                
 NIHarness: an air-gapped, gated, event-sourced multi-agent coding harness.

│ --verbose  -v        Debug logging.                                          │
│ --help               Show this message and exit.                             │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ version     Print the harness version.                                       │
│ init        Probe the hardware, pick a profile and write harness.toml.       │
│ config      Print the merged configuration, as the harness sees it.          │
│ gate        Show the commands the gate would run in this repository.         │
│ status      Fold a run's event log into a snapshot.                          │
│ runs        List this project's runs, with what each one is doing.           │
│ cancel      Ask a run to stop at its next step boundary.                     │
│ mcp         Serve the management surface over stdio, for an agent to drive   │
│             this project.                                                    │
│ brainstorm  Entry A: an interactive session that writes SPEC.md.             │
│ implement   Execute an approved plan, task by task, through the gate.        │
│ run         Plan and implement without stopping for approval.                │
│ resume      Resume a cancelled run from its last snapshot.                   │
│ compact     Compact a run's window now, instead of waiting for the           │
│             threshold.                                                       │
│ research    Run a read-only researcher sub-run over the index.               │
│ bench       Run a benchmark layer and append JSONL records.                  │
│ plan        Plan a spec, validate a plan, or import one written elsewhere.   │
│ docs        Documentation and generated reference material.                  │
╰──────────────────────────────────────────────────────────────────────────────╯
```

```text

 Serve the management surface over stdio, for an agent to drive this project.
```
