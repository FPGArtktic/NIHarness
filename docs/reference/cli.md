## `nih bench`

```text
Usage: nih bench [OPTIONS]                                                     
                                                                                
 Run a benchmark layer and append its JSONL record.                             
                                                                                
 L1 runs every task in `benchmarks/suites/l1` through the same tool loop        
 that runs real work, each in its own copy of the suite's fixture, and          
 scores them by folding the events.                                             
                                                                                
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --layer                       <str>                   L0, L1, L2 or L3.      │
│                                                       [default: L1]          │
│ --project-root        -C      <path>                  The project to operate │
│                                                       on.                    │
│                                                       [default: (.)]         │
│ --profile                     <str>                   Override the profile.  │
│ --repeat                      <int range> [1<=x<=20]  Run the suite this     │
│                                                       many times; one record │
│                                                       per pass, so the       │
│                                                       model's own variance   │
│                                                       is visible rather than │
│                                                       averaged away.         │
│                                                       [default: 1]           │
│ --unsafe-local-tools                                  Run the tools on this  │
│                                                       host instead of in the │
│                                                       sandbox.               │
│ --json                                                Print one JSON object  │
│                                                       instead of the human   │
│                                                       form.                  │
│ --help                                                Show this message and  │
│                                                       exit.                  │
╰──────────────────────────────────────────────────────────────────────────────╯
```

### `nih plan approve`

```text
Usage: nih plan approve [OPTIONS] [PLAN.md]                                    
                                                                                
 Approve a plan, which is what `nih implement` then runs.
```
